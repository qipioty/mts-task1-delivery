# Консольный поиск по Википедии

Консольная программа на Java: принимает поисковый запрос, показывает найденные статьи русской Википедии и открывает выбранную статью в браузере.

Практическая работа №2 по курсу «Объектно-ориентированное программирование».

## Возможности

- ввод поискового запроса с консоли;
- запрос к API Википедии без ключей авторизации;
- разбор JSON-ответа с помощью Gson;
- вывод нумерованного списка результатов с кратким описанием;
- открытие выбранной статьи в браузере по умолчанию;
- корректная обработка ошибок: пустой запрос, ошибки сети, отсутствие результатов, неверный выбор номера.

## Требования

- JDK (версия указана в `pom.xml`)
- Maven (встроен в IntelliJ IDEA)
- доступ в интернет

Готовые библиотеки для работы с Википедией не используются. Единственная внешняя зависимость: [Gson](https://github.com/google/gson) для разбора JSON.

## Использование

1. Введите поисковый запрос и нажмите Enter.
2. Из списка результатов выберите номер статьи, и она откроется в браузере.
3. Введите `0`, чтобы выполнить новый поиск.
4. Введите `exit` на любом шаге, чтобы завершить программу.

Пример:

```
Введите поисковый запрос (exit - выход): ЛЭТИ

Результаты поиска:
1. Санкт-Петербургский государственный электротехнический университет
   ...
2. ...

Введите номер статьи (1-10), 0 - новый поиск, exit - выход: 1
```

## Структура проекта

```
src/main/java/wikisearch
├── Main.java                   точка входа
├── WikiSearchApp.java          основной цикл работы программы
├── ConsoleInput.java           ввод запроса и выбора пользователя
├── WikipediaClient.java        HTTP-запрос к API Википедии
├── ResponseParser.java         разбор JSON-ответа
├── SearchResult.java           модель результата поиска
├── ResultPrinter.java          вывод результатов в консоль
├── BrowserOpener.java          открытие статьи в браузере
└── WikipediaApiException.java  ошибка обращения к API
```

Каждый класс отвечает за одну задачу, что соответствует принципу единственной ответственности.

## Как это работает

1. `ConsoleInput` считывает запрос.
2. `WikipediaClient` кодирует запрос через `URLEncoder` и отправляет его с помощью `HttpClient`.
3. `ResponseParser` превращает JSON в список объектов `SearchResult`.
4. `ResultPrinter` выводит список в консоль.
5. `BrowserOpener` открывает ссылку вида `https://ru.wikipedia.org/w/index.php?curid=<pageid>` через `java.awt.Desktop`.
