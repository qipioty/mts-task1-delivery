# Статистика по справочникам городов (CSV и XML)

Консольная программа на Java, которая читает справочник адресов в формате CSV или XML и формирует сводную статистику.

Практическая работа №3 по курсу «Объектно-ориентированное программирование».

## Возможности

После запуска программа ждёт путь к файлу-справочнику и для него выводит:

1. дублирующиеся записи с количеством повторений;
2. количество 1-, 2-, 3-, 4- и 5-этажных зданий в каждом городе;
3. время обработки файла.

После вывода статистики программа снова ждёт путь к файлу. Завершить работу можно командой `exit`. При ошибках (пустой ввод, несуществующий файл, неподдерживаемый формат, повреждённый файл) программа выводит сообщение и продолжает работу.

## Форматы файлов

Формат определяется по расширению файла.

CSV: разделитель `;`, значения в кавычках, первая строка содержит заголовки.

```
"city";"street";"house";"floor"
"Барнаул";"Дальняя улица";56;2
```

XML: каждая запись это элемент `item` с атрибутами.

```xml
<?xml version="1.0" encoding="utf-8"?>
<root>
<item city="Барнаул" street="Дальняя улица" house="56" floor="2" />
</root>
```

Строки с некорректными данными (не хватает полей, нечисловые дом или этаж) пропускаются, чтобы одна повреждённая запись не прерывала обработку всего файла.

## Требования

- JDK (версия указана в `pom.xml`)
- Maven (встроен в IntelliJ IDEA)

Внешние библиотеки не используются, только стандартная библиотека Java.

## Запуск

1. Склонируйте репозиторий и переключитесь на ветку `practice-3`:

   ```bash
   git clone <адрес репозитория>
   git checkout practice-3
   ```

2. Откройте проект в IntelliJ IDEA.
3. Запустите класс `citystat.Main`.
4. Введите путь к файлу, например `C:\Users\User\Downloads\address.csv`, или `exit` для выхода.

Путь можно вводить в кавычках, например скопированный через «Копировать как путь» в проводнике Windows.

## Структура проекта

```
src/main/java/citystat
├── Main.java                   точка входа
├── CityStatApp.java            основной цикл работы программы
├── ConsoleInput.java           ввод пути и команды выхода
├── ParserFactory.java          выбор парсера по расширению файла
├── AddressParser.java          общий интерфейс парсеров
├── CsvAddressParser.java       чтение CSV
├── XmlAddressParser.java       чтение XML
├── Address.java                модель записи (record)
├── StatisticsCalculator.java   подсчёт статистики
├── AddressStatistics.java      результат подсчёта
├── FloorCounter.java           счётчик зданий по этажности
├── StatisticsPrinter.java      вывод статистики
└── AddressParseException.java  ошибка чтения файла
```

Каждый класс отвечает за одну задачу. Парсеры CSV и XML реализуют общий интерфейс `AddressParser`, поэтому формат файла можно заменить или добавить новый без изменения остальной логики: достаточно написать новую реализацию интерфейса и добавить её в `ParserFactory`.

## Как это работает

1. `ConsoleInput` считывает путь.
2. `ParserFactory` выбирает парсер по расширению.
3. Парсер читает файл и возвращает список `Address`.
4. `StatisticsCalculator` за один проход подсчитывает дубликаты и количество зданий по этажности.
5. `StatisticsPrinter` выводит результат и время обработки.

## Скорость работы

- `Address` это `record`, поэтому `equals` и `hashCode` генерируются автоматически, а записи можно использовать как ключи `HashMap`.
- Дубликаты и этажность считаются за один проход по данным с помощью `HashMap`, без вложенных циклов и сравнения записей попарно.
- XML читается потоковым парсером StAX, который не строит дерево документа в памяти.
- CSV читается построчно через `BufferedReader`.
- Размер `HashMap` задаётся заранее, чтобы избежать перестроений таблицы.
- Счётчики этажности хранятся в массиве `int[]`.

Допущение: в статистике по этажности каждое здание учитывается один раз, повторяющиеся записи считаются дубликатом одного и того же здания.
